A deadpan one-star review of sleep, the most essential thing there is. It asks for a third of every day and offers nothing in return but a receipt.

Running `main.py` writes the review to `entry.txt` inside the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).
